DMZ Clients

          Isolate a client from the LAN while keeping it reachable from the internet.
        

        

          ⚠
          

            Soft DMZ — iptables isolation

            DMZ clients share the LAN subnet. Isolation is enforced by FORWARD DROP rules
            that block the DMZ client from initiating connections to any other LAN host.
            The DMZ client can still reach the gateway (DNS / management) and the internet.
            A static DHCP reservation is required so port forwards always
            reach the correct host.

Signature detections are read live from /var/log/suricata/eve.json and also feed the AI Threat Summary above. Suricata runs as a passive IDS: it inspects a copy of each packet via af-packet and never sits in the forwarding path, so internet throughput is unaffected. Install and enable Suricata on the LAN/WAN interfaces to populate this table.
