# Custom blocklist
# One IP or CIDR per line. Lines starting with '#' are comments.
#
# Managed from the dashboard (CrowdSec > Custom Banlist). Hand edits are
# applied by the dashboard API within 6 hours (or at once with
# `sudo systemctl reload tuxwall`); entries become 1-year CrowdSec bans.
#
# Examples:
#   192.0.2.1
#   198.51.100.0/24
#
